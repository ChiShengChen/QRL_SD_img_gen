# 量子 vs 經典模型比較功能總結

## 🎯 概述

本項目實現了全面的量子與經典模型比較功能，包含 **22個不同的評估指標**，涵蓋性能、效率、控制、圖像質量等多個維度。

## 📊 可用的比較腳本

### 1. **快速比較** (原有功能)
```bash
python run_quick_comparison.py
```
**比較指標**: 4個基本指標
- 參數數量
- 平均獎勵
- 平均時間/Episode
- 穩定性 (std)

### 2. **全面比較** (新功能)
```bash
python run_comprehensive_comparison.py
```
**比較指標**: 28個全面指標
- 基本性能指標 (4個)
- 圖像質量指標 (4個)
- 控制性能指標 (4個)
- 效率指標 (4個)
- 量子特定指標 (8個)
- 量子 vs 經典比較 (4個)

### 3. **簡化版全面比較** (新功能)
```bash
python run_simple_comprehensive_comparison.py
```
**比較指標**: 16個核心指標
- 基本性能指標 (4個)
- 控制性能指標 (4個)
- 效率指標 (4個)
- 量子 vs 經典比較 (4個)

### 4. **指標測試** (新功能)
```bash
python test_metrics_only.py
```
**功能**: 測試所有指標計算功能，不依賴擴散環境

## 🔬 詳細指標列表

### 基本性能指標 (4個)
1. **參數數量** - 模型總參數數
2. **平均獎勵** - 任務表現
3. **平均時間/Episode** - 推理速度
4. **穩定性** - 輸出一致性

### 圖像質量指標 (4個)
1. **分類準確率** - 目標類別識別準確性
2. **FID分數** - 生成圖像與真實圖像的距離
3. **IS分數** - 圖像多樣性和質量
4. **LPIPS** - 感知相似性

### 控制性能指標 (5個)
1. **回合獎勵** - 平均回合獎勵
2. **收斂速度** - 達到穩定性能的速度
3. **CFG平滑度** - 控制軌跡的平滑性
4. **策略穩定性** - 學習過程的穩定性
5. **CFG範圍** - CFG值的變化範圍

### 效率指標 (5個)
1. **參數效率** - 性能/參數比
2. **推理效率** - 推理速度效率
3. **記憶體效率** - 記憶體使用效率
4. **訓練效率** - 學習速度效率
5. **計算效率** - 計算資源利用

### 量子特定指標 (8個)
1. **量子相干性** - 量子態的相干性保持
2. **量子優勢** - 相對於經典模型的優勢程度
3. **量子糾纏** - 量子電路中的糾纏程度
4. **量子門效率** - 量子門的使用效率
5. **量子噪聲魯棒性** - 對量子噪聲的抵抗能力
6. **量子梯度質量** - 量子梯度的質量和穩定性
7. **量子表達能力** - 量子模型的表達能力
8. **量子學習動態** - 量子模型的學習動態

### 量子 vs 經典比較 (4個)
1. **性能改善** - 量子模型相對於經典模型的性能提升
2. **參數效率比** - 參數效率的比較
3. **速度改善** - 推理速度的比較
4. **記憶體效率比** - 記憶體效率的比較

## 🚀 使用建議

### 快速驗證
```bash
python test_metrics_only.py  # 測試指標功能
python run_quick_comparison.py  # 快速比較
```

### 全面分析
```bash
python run_comprehensive_comparison.py  # 完整比較 (需要CUDA)
python run_simple_comprehensive_comparison.py  # 簡化比較 (CPU)
```

### 論文發表
使用 `run_comprehensive_comparison.py` 獲取完整的28個指標數據，適合學術論文和詳細分析。

## 📝 注意事項

1. **硬體要求**: 完整版需要CUDA支持，簡化版可在CPU上運行
2. **運行時間**: 全面比較需要較長時間，建議使用較少的episode數
3. **指標解釋**: 某些指標值為0是正常的，表示該特性在當前配置下未激活
4. **結果保存**: 所有結果會自動保存為JSON文件

## 🔧 自定義配置

可以通過修改腳本中的參數來自定義比較：
- `num_episodes`: 實驗回合數
- `max_steps`: 每回合最大步數
- `target_class`: 目標類別
- `device`: 計算設備

## 📊 輸出文件

- `quick_comparison_results.json`: 快速比較結果
- `comprehensive_comparison_results.json`: 全面比較結果
- `simple_comprehensive_comparison_results.json`: 簡化比較結果

這些文件包含完整的實驗數據，可用於進一步分析和可視化。
